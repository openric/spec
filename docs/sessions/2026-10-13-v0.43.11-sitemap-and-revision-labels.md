# 2026-10-13 - v0.43.11: sitemap, and version headers relabelled

Commit `5c2211b` on `openric/spec`, tag `v0.43.11`. Requested by Dr Johan Pieterse.

## What prompted it

Item O01 / F09 of the AHG Ecosystem SEO and Marketing Implementation Plan V1 (13 October 2026) asked for one machine-readable version manifest feeding the site, done when the homepage, `/spec/`, the repository, the sitemap and the README all show the same current stable version. The plan said the homepage showed v0.43.10 and `/spec/` showed v0.37.0.

Most of that had shipped on 28 September in `2421926`: `version.json` mirrored to `_data/version.json`, fourteen pages rendering from it, and `bin/check-versions.py` failing CI on drift. Checked against the live site before starting, three gaps remained.

## What shipped

- **Sitemap.** `/sitemap.xml` returned 404 and `_config.yml` declared no plugins. `jekyll-sitemap` is now enabled; it is on the GitHub Pages allow-list, so no Gemfile or custom build is needed. It also emits a `robots.txt` pointing at the sitemap, which the site did not have.
- **Document headers.** `viewing-api.md`, `graph-primitives.md`, `conformance.md` and `mapping.md` carried a hand-typed `**Version:** 0.37.0` (0.38.1 on mapping). A reader takes that as the current release. They now read `**Last revised in:** v0.37.0`. The twelve profile pages said `**Spec version:**`; they now say `**Last revised in spec:**`, which is what `profiles/index.md` already defines that number to mean.
- **`/spec/` tables.** The profile table column is "Last revised in spec". The mapping row no longer reads "0.1.0-draft → v0.37.0".
- **Checker.** A bare `**Version:**` or `**Spec version:**` header is now a currency claim. Tested both ways: green on the tree, red when the old header is put back on `conformance.md`.

`spec/profiles/index.md` carried `**Version:** 0.3.0-draft`, which the new rule flags. The label became "Profile framework version" with the value untouched. That page's header is dated 19 April 2026 and wants a proper revision.

## Verified on the live site after the Pages build

`/sitemap.xml` 200 with 119 URLs; `/robots.txt` names it; `/version.json` and the homepage show 0.43.11; `/spec/` shows v0.43.11 as current, and its one remaining v0.37.0 is the prose history of the RiC-O 1.1 remediation, which is correct.
