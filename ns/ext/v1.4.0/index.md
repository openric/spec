# OpenRiC Extension Ontology, version 1.4.0

**Version IRI:** `https://openric.org/ns/ext/v1.4.0` · **Released:** 2026-10-19 · **Specification:** v0.53.0

A past release; [1.5.0](/ns/ext/v1.5.0/) is the current one. The copy fixed at this release is in the specification repository at the `v0.53.0` tag. It adds the four assertion-provenance properties of the Inferred-Provenance profile; [1.3.1](/ns/ext/v1.3.1/) is the release before it.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
