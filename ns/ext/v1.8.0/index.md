# OpenRiC Extension Ontology, version 1.8.0

**Version IRI:** `https://openric.org/ns/ext/v1.8.0` · **Released:** 2026-11-16 · **Specification:** v0.58.0

Superseded by [1.9.0](/ns/ext/v1.9.0/). The copy fixed at this release is in the specification repository at the `v0.58.0` tag. It adds the kind of a name or title, `openricx:hasNameType`, with the [name-type vocabulary](/vocab/name-type.html) (openric/spec#64); a title or name that translates another, `openricx:isTranslationOf` (#74); and the text of an instantiation, `openricx:transcript` (#65), and what an image shows, `openricx:alternativeText` (#66). [1.7.0](/ns/ext/v1.7.0/) is the release before it.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
