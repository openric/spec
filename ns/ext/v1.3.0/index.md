# OpenRiC Extension Ontology, version 1.3.0

**Version IRI:** `https://openric.org/ns/ext/v1.3.0` · **Released:** 2026-10-19 · **Specification:** v0.52.0

Superseded by [1.3.1](/ns/ext/v1.3.1/). The Turtle fixed at this release is in the specification repository at the `v0.52.0` tag. It adds the role-in-relation, kinship-of-care and carrier terms; [1.2.0](/ns/ext/v1.2.0/) is the release before it.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
