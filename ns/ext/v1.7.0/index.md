# OpenRiC Extension Ontology, version 1.7.0

**Version IRI:** `https://openric.org/ns/ext/v1.7.0` · **Released:** 2026-11-04 · **Specification:** v0.57.0

The release after [1.6.1](/ns/ext/v1.6.1/). The copy of its Turtle fixed at this release is in the specification repository at the `v0.57.0` tag. It adds whether a rule is in force, `openricx:hasRuleStatus`, and amendment and supersession between rules: `openricx:amendsOrAmended`, `openricx:supersedesOrSuperseded` and their inverses.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
