# OpenRiC Extension Ontology, version 1.5.0

**Version IRI:** `https://openric.org/ns/ext/v1.5.0` · **Released:** 2026-10-20 · **Specification:** v0.54.0

The release before [1.6.0](/ns/ext/v1.6.0/). The copy of its Turtle fixed at this release is in the specification repository at the `v0.54.0` tag. It sets the range of `openricx:hasDateRangeSet` to `openricx:DateRange`, as every implementation uses it; [1.4.0](/ns/ext/v1.4.0/) is the release before it.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
