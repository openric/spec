# OpenRiC Extension Ontology, version 1.6.1

**Version IRI:** `https://openric.org/ns/ext/v1.6.1` · **Released:** 2026-11-03 · **Specification:** v0.56.17

The release after [1.6.0](/ns/ext/v1.6.0/). The copy of its Turtle fixed at this release is in the specification repository at the `v0.56.17` tag. It adds close matches to BoDi (w3id.org/bodi) for the digital-object terms; no term was added or removed.

The terms themselves do not change IRI between versions: every term is `https://openric.org/ns/ext/v1#<name>`. The [ontology page](/ns/ext/v1.html) lists them, with the version history.
